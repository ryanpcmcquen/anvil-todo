# anvil-todo-demo

A full-stack TODO app demonstrating compile-time dependency injection with [@anvil-di/anvil](https://www.npmjs.com/package/@anvil-di/anvil) and [@anvil-di/bellows](https://www.npmjs.com/package/@anvil-di/bellows).

- **Express API** — DI-wired controllers with Zod-validated request/response schemas
- **React frontend** — TanStack Query client generated from an OpenAPI spec
- **Zero runtime reflection** — all wiring is generated TypeScript, checked by your own `tsc`

## How it works

The codegen pipeline runs automatically as part of `vite build` / `vite dev`:

```
bellowsCodegen()     →  routes.module.anvil.ts        (validated Express routes)
                        schema-route.module.anvil.ts  (OpenAPI spec route)
anvil build          →  app-component.anvil.ts        (DI wiring)
bellowsOpenApi()     →  server/src/openapi.json       (OpenAPI 3.1 spec)
```

The generated `*.anvil.ts` files are plain TypeScript — no magic at runtime. After running `pnpm generate:client`, the React frontend gets a fully-typed API client from `src/api/`.

## Prerequisites

- Node.js 20+
- pnpm 9+

## Getting started

```sh
pnpm install
pnpm generate:client
```

### Development

Run the API server and Vite dev server in separate terminals:

```sh
pnpm dev:server   # Express on http://localhost:3001
pnpm dev:client   # Vite + codegen on http://localhost:5173
```

`dev:client` runs the full codegen pipeline on startup so the `*.anvil.ts` files are always fresh.

### Regenerate the API client

After changing a controller, rebuild to get a fresh OpenAPI spec and regenerate the typed client:

```sh
pnpm generate     # vite build + hey-api openapi-ts
```

### Type-check

```sh
pnpm typecheck
```

### Run tests

```sh
pnpm test         # Playwright E2E (starts both servers automatically)
pnpm test:ui      # Playwright UI mode
```

## Project structure

```
server/src/
  todo-controller.ts        @Controller with @Get/@Post/@Put/@Delete, Zod schemas
  todo-service.ts           In-memory store
  todo-module.ts            @Module wiring TodoService as a @Singleton
  app-component.ts          @Component root — entry point for anvil codegen
  spec-component.ts         @Component for the OpenAPI spec server
  server.ts                 Express app

src/
  components/
    TodoList.tsx            Fetches todos, handles filter tabs
    AddTodo.tsx             Form to create a new todo
    TodoItem.tsx            Toggle complete, delete
  api/                      Generated by @hey-api/openapi-ts (gitignored)
```

## Key packages

| Package | Role |
|---|---|
| `@anvil-di/anvil` | Decorator stubs (`@Module`, `@Component`, `@Provides`, `@Singleton`, `@Inject`) |
| `@anvil-di/anvil-unplugin` | Vite plugin that runs the codegen pipeline on every build |
| `@anvil-di/bellows` | Controller decorators (`@Controller`, `@Get`, etc.) and `bellowsCodegen()` hook |
| `@anvil-di/bellows-openapi` | `bellowsOpenApi()` hook that writes `openapi.json` after the build |
| `@hey-api/openapi-ts` | Generates the typed React client from `openapi.json` |
| `@tanstack/react-query` | Data fetching and cache invalidation in the React frontend |
